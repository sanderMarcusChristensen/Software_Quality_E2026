2. ----- FristName : ----------

  Partitions:

    Valid:
        1-30 characters
        Alphabetic characters
        Alphabetic characters and spaces
        Alphabetic characters and dashes

    Invalid:
        0 characters
        31 characters or more
        Contains numbers
        Contains special characters
        Only spaces or dashes
        Not a string

Boundary value analysis – lower boundary:

        0 characters → invalid
        1 character  → valid
        2 characters → valid

Boundary value analysis – upper boundary:

        29 characters → valid
        30 characters → valid
        31 characters → invalid

Test case list:

        ""                  → invalid, 0 characters
        "A"                 → valid, 1 character
        "AB"                → valid, 2 characters
        "A" * 29            → valid, 29 characters
        "A" * 30            → valid, 30 characters
        "A" * 31            → invalid, 31 characters
        "Anne Marie"        → valid, space
        "Anne-Marie"        → valid, dash
        "Søren"             → valid, Danish letter
        "Sander123"         → invalid, numbers
        "Sander!"           → invalid, special character
        "   "               → invalid, only spaces
        "---"               → invalid, only dashes
        123                 → invalid, not a string

8. ----- getSalary : ----------

    Formel: Actual salary = base salary + (educational level × 1220)

Partitions:

    Educational level 0:
        No educational addition

    Educational level 1:
        Addition of 1220 DKK

    Educational level 2:
        Addition of 2440 DKK

    Educational level 3:
        Addition of 3660 DKK

Test : 
Base salary 20000, level 0:

        20000 + (0 × 1220) = 20000

Base salary 20000, level 1:

        20000 + (1 × 1220) = 21220

Base salary 20000, level 2:

        20000 + (2 × 1220) = 22440

Base salary 20000, level 3:

        20000 + (3 × 1220) = 23660

Base salary 50000, level 3:

        50000 + (3 × 1220) = 53660

Base salary 100000, level 3:

        100000 + (3 × 1220) = 103660


9. ----- getDiscount : ---------- 

Formel : Discount = completed years of employment × 0.5

Partitions:

    Less than 1 completed year:
        0% discount

    Exactly 1 completed year:
        0.5% discount

    More than 1 completed year:
        Number of completed years × 0.5


Boundary value analysis
    One day before completing 1 year → 0 years → 0%
    Exactly 1 completed year         → 1 year  → 0.5%
    One day after completing 1 year  → 1 year  → 0.5%

Test: 

    Date of employment = today
    Expected discount = 0%

    Date of employment = one day less than 1 full year ago
    Expected discount = 0%

    Date of employment = exactly 1 year ago
    Expected discount = 0.5%

    Date of employment = 1 year and 1 day ago
    Expected discount = 0.5%

    Date of employment = exactly 5 years ago
    Expected discount = 2.5%

    Date of employment = exactly 10 years ago
    Expected discount = 5.0%

11. ----- Getters / Setters  : ----------  
Partitions:

    Valid value:
        Setter accepts the value
        Getter returns the stored value

    Invalid value:
        Setter raises the expected exception
        Invalid value is not stored

    Test 
    
    set_cpr("1111111111")
    get_cpr() returns "1111111111"

    set_first_name("Anne-Marie")
    get_first_name() returns "Anne-Marie"

    set_last_name("Jensen Larsen")
    get_last_name() returns "Jensen Larsen"

    set_department("Finance")
    get_department() returns "Finance"

    set_base_salary(40000)
    get_base_salary() returns 40000

    set_educational_level(2)
    get_educational_level() returns "secondary"

    set_date_of_birth("01/01/1990")
    get_date_of_birth() returns "01/01/1990"

    set_date_of_employment("01/01/2020")
    get_date_of_employment() returns "01/01/2020"

    set_country("Sweden")
