# Software_Quality_E2026

## Running Tests with Pytest

### Step 1: Activate the Virtual Environment
Navigate to the Lesson1 folder and run:
```bash
source .venv/bin/activate
```

### Step 2: Run Pytest
```bash
pytest calculator_test.py -v
```

### Notes
- Make sure you are in the correct folder (ex : Lesson1) before running the command
- The `(.venv)` prefix in your terminal shows the virtual environment is active
- To exit the virtual environment, type: `deactivate`
